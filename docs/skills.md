# Skills and prompt recipes

`/{locale}/skills` provides six independently authored prompt recipes and eight adaptations of published Higgsfield AI MIT prompt contracts. Search, media/favorite/custom filters, variable forms and an editable preview precede generation. Preparing a prompt makes no model call. **Open draft** transfers the reviewed prompt through session-only browser storage to the existing image/video composer; the user must select their model, attach references and explicitly submit generation. Reference-based recipes block composer submission until the required image count is attached. Prompts and subjects are not placed in URLs. This is a prompt-recipe runner, not a general autonomous agent or the complete Higgsfield skill execution system.

The current shared owner's custom recipes and favorites are persisted in `STUDIO_SETTINGS_DIR/skill-library.json` (directory 0700, file 0600), outside public source. Writes are atomic and serialized within the single application process; whole-library revision checks reject concurrent stale edits. Do not run multiple writer processes against this file. Corrupt stores fail closed and are never silently reset. Maximum 200 custom recipes; templates are inert text with up to eight `{{variable_names}}` placeholders. No scripts, arbitrary file reads, installers or tools execute from a recipe.

`GET /api/skills` returns the catalog, favorites and current library revision. Same-origin JSON `POST /api/skills` accepts `{action:"save",revision,id?,recipe:{name,description,mediaType,template}}`, `{action:"remove",revision,id}` or `{action:"favorite",revision,id,favorite}`. All data remains under the existing deployment's shared-owner authentication boundary. These APIs do not add multiuser isolation, public signup or scoped client credentials. Keep the reverse proxy in place.

The **Open-source skills** tab opens an in-app reader for all eight official skills and 86 published Markdown documents, with per-document downloads and source-bundle exports including the complete MIT notice. All text is inert: shell commands, installers and skill instructions are never executed by the reader. Original sources retain their actual hosted CLI/model/dependency requirements. Product Photoshoot and Marketplace Cards explicitly keep their final prompt enhancers private on the hosted backend; this release does not pretend those prompts were published.

`src/lib/licensed-prompts.ts` identifies the eight public adaptations by upstream commit, document and line range. Remixing and JSON exports retain attribution and the full MIT notice. These prompts do not guarantee identity, geometric, logo or editing fidelity; the selected engine must support their references and output modality. Choosing an image model does not produce editable SVG merely because the prompt describes a vector style.

Regenerate the inert source artifact with `npm run sources:skills` after initializing the pinned submodules. The importer requires the exact clean upstream revision and matching license hash; it imports only the eight SKILL.md files and their Markdown references. `src/content/licensed-skill-reference.json` is a public licensed reference artifact, not runtime account data. Provider credentials, private custom recipes and project state must never be placed beside it. Tests compare document/license fingerprints and source allowlists.

JSON recipe exports contain only the selected template and its attribution, not provider credentials or the rest of the library. Import, autonomous multi-step execution and general skill version-history editing are not implemented.

Run `npm run test:skills` for isolated template, persistence, concurrency, restart, bounded-body, Origin, reference and license/source integrity contracts. No paid generation is performed by these tests. Real provider output verification remains separate.
