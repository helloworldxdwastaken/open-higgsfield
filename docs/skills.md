# Skills and prompt recipes

`/{locale}/skills` provides six independently authored prompt recipes, search, media/favorite/custom filters, a variable form and an editable prompt preview. Preparing a prompt makes no model call. **Open draft** transfers the reviewed prompt through session-only browser storage to the existing image/video composer; the user must select their model, attach references and explicitly submit generation. Prompts and subjects are not placed in URLs. This is a prompt-recipe runner, not a general autonomous agent or the complete Higgsfield skill execution system.

The current shared owner's custom recipes and favorites are persisted in `STUDIO_SETTINGS_DIR/skill-library.json` (directory 0700, file 0600), outside public source. Writes are atomic and serialized within the single application process; whole-library revision checks reject concurrent stale edits. Do not run multiple writer processes against this file. Corrupt stores fail closed and are never silently reset. Maximum 200 custom recipes; templates are inert text with up to eight `{{variable_names}}` placeholders. No scripts, arbitrary file reads, installers or tools execute from a recipe.

`GET /api/skills` returns the catalog, favorites and current library revision. Same-origin JSON `POST /api/skills` accepts `{action:"save",revision,id?,recipe:{name,description,mediaType,template}}`, `{action:"remove",revision,id}` or `{action:"favorite",revision,id,favorite}`. All data remains under the existing deployment's shared-owner authentication boundary. These APIs do not add multiuser isolation, public signup or scoped client credentials. Keep the reverse proxy in place.

The **Open-source skills** tab links eight MIT-licensed official sources pinned in [upstream-sources.json](upstream-sources.json). It labels them external references: their hosted Higgsfield CLI, models and scripts are not executed or falsely advertised as free local implementations. Native recipes are original Highfield content. JSON recipe exports contain only the selected template, not provider credentials or the rest of the library. Import, autonomous multi-step execution and general skill version-history editing are not implemented.

Run `node tests/skills.cjs` for isolated template, persistence, concurrency, restart, bounded-body and Origin contracts. No paid generation is performed by these tests. Real provider output verification remains separate.
